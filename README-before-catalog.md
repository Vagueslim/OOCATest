URL สำหรับเดโม: **https://vagueslim.github.io/OOCATest/**

ตรวจเปิดเว็บจริงและ flow หลักผ่านแล้ววันที่ 2026-11-06: [ผลตรวจ GitHub Pages](evidence/pages-verification.md) รวมจบก่อนเลือก ข้ามทั้งหมดหลังเลือก และจบเมื่อเก็บไม่สำเร็จ

Workflow `.github/workflows/pages.yml` build ด้วย `npm ci` และ `npm run build` แล้วเผยแพร่เฉพาะ `dist` ผ่าน GitHub Pages เมื่อซอร์สบน `main` เปลี่ยน หรือสั่ง `workflow_dispatch` ไม่เปลี่ยน visibility ของ repository

`vite.config.ts` ใช้ base `/OOCATest/` สำหรับ production build/preview และ `/` สำหรับ dev server Vite ปรับ URL ของ JavaScript, CSS และฟอนต์ local ให้ตรงกับ repository path หน้าต่าง ๆ ใช้ React state จึงคง URL เดิมและรีโหลดกลับหน้าเริ่มต้นได้โดยไม่ต้องตั้ง SPA fallback

ตรวจเว็บที่เผยแพร่แล้วด้วย `node tests/pages-smoke.mjs https://vagueslim.github.io/OOCATest/` ผลและภาพจะอยู่ใน `evidence/live/` ซึ่งไม่ commit ข้อมูลที่เก็บใน localhost จะไม่ย้ายไปเว็บจริง เพราะเป็นคนละ origin

เดโมมือถือภาษาไทย React + TypeScript + Vite ตามสเปก `docs/superpowers/specs/2026-11-06-ooca-react-demo-design.md` (2026-11-06) ใช้ข้อความทั้ง 15 ข้อตามสเปก ไม่มีบัญชีหรือ backend

ปุ่มหลักใช้ข้อความ `#272727` บน turquoise แทนข้อความขาว สีฟ้าใช้แสดงโฟกัสและสีทองเป็นองค์ประกอบตกแต่ง ตรวจ contrast ที่เรนเดอร์จริงใน `evidence/contrast.json` และตรวจข้อความทั้งหมดด้วย visual lint การเปลี่ยนธีมไม่เปลี่ยนข้อความ โครงสถานะ การสุ่ม หรือกติกาเก็บข้อมูล

ผล contrast ข้อความขนาดปกติ: ปุ่มหลัก **6.79:1**, hover **5.62:1**, ทางจบและตัวเลือกที่เลือก **13.46:1** ทั้งหมดผ่านเกณฑ์ AA 4.5:1 และยืนยันว่า Prompt โหลดสำเร็จในเบราว์เซอร์ (`fontLoaded: true`)

ใช้ **Prompt Regular / SemiBold** แบบไฟล์ local จาก [Google Fonts / Cadson Demak](https://github.com/google/fonts/tree/main/ofl/prompt) ตรวจใบอนุญาต SIL Open Font License 1.1 แล้วและแนบฉบับเต็มที่ `public/fonts/OFL.txt` ฟอนต์ไม่ได้แก้ไข ไฟล์ต้นฉบับอยู่ใน `public/fonts/` และโหลดจาก origin เดียวกับเดโม ไม่มีการโหลดฟอนต์หรือรูปจากบริการภายนอกขณะใช้งาน

ข้อจำกัด asset: ไม่พบไฟล์และหลักฐานสิทธิ์สำหรับ Gotham Rounded หรือ Mooca ในโปรเจกต์ จึงใช้ Prompt ซึ่งรองรับทั้งไทยและอังกฤษ และ fallback `Leelawadee UI, Tahoma, sans-serif` ภาพรับกอดยังเป็น SVG ตกแต่งเดิมที่สร้างสำหรับเดโมและปรับสีใหม่ **ไม่ใช่ Mooca หรือโลโก้ OOCA** รอบนี้ใช้ค่า CI ที่ส่งมา ไม่ได้ดึง asset เพิ่มจาก Figma และไม่ใช้ URL ชั่วคราวของ Figma

## เริ่มใช้งาน

ใช้ Node.js 20.19+ หรือ 22.12+ (ตรวจบน Node 24.16.0)

```sh
npm install
npm run dev
npm run build
npm run preview
```

เปิด URL localhost ที่ Vite แสดง ใช้ origin เดิมเมื่อต้องการอ่านบันทึกเดิม `dev` และ `preview` ใช้คนละ port จึงมี localStorage แยกกัน

## ทดสอบซ้ำ

```sh
npx playwright install chromium --only-shell
npm test
```

Playwright เปิด localhost เอง ใช้ browser context แยกแต่ละกรณี และสร้างรายงาน `evidence/test-results.json` กับ `evidence/report/index.html` เริ่มตรวจ A02, A04, A06 ตามสเปก จากนั้นตรวจเส้นทางเสริมและข้อผิดพลาด อ่านผลล่าสุดในรายงานดังกล่าว

## พฤติกรรมสำคัญ

- หน้าพบข้อความมีทางเลือก 4 ทาง: เลือก เปลี่ยน วันนี้ยังไม่เลือก และจบได้เลย
- สับสำรับ 15 คำต่อรอบ ไม่ซ้ำจนหมด และไม่ซ้ำติดกันตรงรอยต่อสำรับ
- หน้าอ่านทวนระบุมุม พิมพ์ เก็บ หรือข้ามทุกอย่างได้ มีทางจบบนและล่าง
- ข้อความพิมพ์เองเป็นข้อความธรรมดา จำกัด 500 ตัวอักษร ไม่บันทึกลง localStorage และล้างเมื่อจบรอบ/รีโหลด
- การเก็บเป็นการกระทำโดยผู้ใช้ มีหนึ่งบันทึกต่อรอบ สูงสุด 3 รายการที่ยังอยู่ต่อวันท้องถิ่น อัปเดตเฉพาะมุมโดยไม่เปลี่ยนวัน/เวลาที่เก็บครั้งแรก
- เมื่อเต็ม ข้อมูลเสีย หรืออ่าน/เขียนไม่ได้ แสดงข้อผิดพลาดและจบต่อได้ ข้อมูลเสียไม่ถูกเขียนทับอัตโนมัติ
- ใช้คีย์ `ooca-demo:saved-quotes:v1` ประวัติเลือกเดือน เปิดอ่าน และลบหลังยืนยัน ลบสำเร็จจึงคืนพื้นที่
- การเก็บอยู่ในเบราว์เซอร์และ origin นี้เท่านั้น ไม่ส่งข้อความหรือข้อมูลให้บริการภายนอก รองรับเดโมเครื่องเดียวแท็บเดียวตามสเปก

## โครงสร้าง

`src/App.tsx` ควบคุม 6 สถานะและรอบ, `QuoteCard.tsx` แสดงคำ, `HistoryView.tsx` ดู/ลบประวัติ, `quotes.ts` คลังคำและสุ่ม, `storage.ts` ตรวจ/เขียนข้อมูล, `style.css` รูปแบบมือถือและเดสก์ท็อป
